RunGame - TPSIT & Cybersecurity Zero-Day Edition

Progetto interattivo in p5.js basato sull'esercitazione *RunGame*. Il gioco simula una gara tra diverse categorie di argomenti di TPSIT (Sistemi Operativi e Cybersecurity), estraendo una domanda casuale alla vittoria del primo concorrente.

Funzionalità principali
- Corridori dinamici: 4 concorrenti con colori differenti associati ad argomenti specifici.
- Legenda integrata: Corrispondenza visiva tra colore e argomento di TPSIT/Security.
- Macchina a Stati: Gestione fluida delle fasi di gioco (`RACE`, `QUESTION`, `END`).
- Sistema Challenge: Estrazione casuale di una domanda al superamento della linea d'arrivo *Target Zero-Day*.
- Interazione da tastiera: Digitazione live della risposta e riavvio della gara con il tasto `R`.

Vincoli del Progetto
- Libreria p5.js importata via CDN.
- Utilizzo di cicli e strutture dati (array di oggetti) per gestire concorrenti e domande.

Come eseguire il gioco
Aprire il file `index.html` in un qualsiasi browser web oppure utilizzare un server locale come *Live Server* su VS Code.
